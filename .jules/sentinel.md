## 2024-03-25 - Hardcoded JWT Secret Key in Source Code
**Vulnerability:** A hardcoded, plaintext JWT secret key ("your_secret_key") was found embedded directly in `internal/auth/auth.go`. This allows anyone with access to the source code to forge valid JWT tokens, completely bypassing authentication and gaining unauthorized access to the application.
**Learning:** Hardcoding cryptographic secrets directly into source files is a common but critical anti-pattern. While it might seem convenient during early development or prototyping, it permanently compromises the security of the application once the code is committed. Secrets must be treated as configuration data, fundamentally separate from application logic, and injected at runtime.
**Prevention:** Never commit plaintext secrets, API keys, or passwords to version control. Utilize environment variables (e.g., `os.Getenv("JWT_SECRET")`) or dedicated secrets management solutions to securely inject sensitive configuration at runtime. Implement automated pre-commit hooks and CI/CD secret scanning tools (like Gitleaks or TruffleHog) to detect and block secrets before they enter the repository. Ensure application code defensively checks for the presence of required secrets at startup and fails securely if they are missing, preventing insecure fallback states.
