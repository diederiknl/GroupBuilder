## 2024-03-16 - Hardcoded JWT Secret Vulnerability
**Vulnerability:** A hardcoded `jwtKey` secret (`"your_secret_key"`) was embedded in the source code of `internal/auth/auth.go`, enabling unauthorized JWT signing, validation, and arbitrary token generation leading to complete authentication bypass.
**Learning:** Hardcoding credentials makes the application vulnerable to credential theft, especially if the source code is compromised or public. This is a critical security vulnerability that often gets overlooked in initial implementations or prototypes. The use of Go 1.16 requires particular care when unit testing environment variable behavior by using `os.Setenv` and `defer os.Setenv` since `t.Setenv` is missing.
**Prevention:** Always load sensitive credentials and secrets from a secure external source, such as environment variables (`os.Getenv`), a secrets manager, or configuration files that are excluded from version control. Ensure the application fails securely (returns an error) if the required secrets are not provided.
